🎯 核心理念：DAU 目标驱动
全链路的终极目标不是"运行流程"，而是"达成网站 DAU 目标"。系统以 DAU 为北极星指标，反向计算所需资源，自动调度全链路。
10,000
每日网站 DAU 目标（可配置）
DAU 达成公式： 发布内容数 × 单帖引流率 + 主动触达数 × 触达转化率 + 截流评论数 × 评论转化率 ≥ DAU目标
决策引擎实时监控 DAU 缺口 → 自动增加内容产出 / 加大主动营销 / 扩展账号池 → 闭环优化

填补现有系统与 DAU 目标驱动全链路之间的关键缺口。

P0 · social-bridge.js

关键路径
云手机社媒操作桥接层。将 device-manager.js 的 50 台云手机连接到实际社媒平台，执行发帖、关注、私信、评论等操作。每台设备分配独立 Playwright 浏览器上下文，加载 session-manager.js 的 Cookie/LocalStorage 恢复登录态。
核心方法：postContent(deviceId, , content) followUser(deviceId, targetUser) sendDM(deviceId, targetUser, message) commentOnPost(deviceId, postUrl, comment)
依赖：device-manager.js session-manager.js stealth-injector.js

P0 · dau-target-controller.js

核心中枢
DAU 目标驱动控制器。系统的"大脑"。用户设定每日 DAU 目标，控制器基于历史转化率反推所需资源（内容数、触达数、截流数），生成每日执行计划，下发给各模块。实时监控 DAU 进度，动态调整策略。
核心方法：setTarget(dau) planDaily() monitorProgress() adjustStrategy()
依赖：decision-engine.js website-analytics.js 所有执行模块

P1 · proactive-marketing.js

主动触达
主动营销引擎。弥补 SCRM 截流仅能"被动回复"的不足。主动搜索目标用户 → 关注 → 等待回关 → 私信引流。话题参与：搜索相关话题标签 → 发布评论/帖文。KOL 互动：监控大V发帖 → 第一时间评论增加曝光。
核心方法：findTargetUsers(, keywords) followAndWait(deviceId, userId) sendDM(deviceId, userId, template) engageTopic(deviceId, hashtag)
依赖：social-bridge.js scrm-intercept.js

P1 · aigc-content-generator.js

内容工厂
AIGC 内容生成器。集成 LLM API（GPT-4o / Claude 3.5），基于 content-intelligence.js 的热点关键词和 Content DNA 模板，自动生成多平台适配的文案、标题、脚本。每条内容自动嵌入引流 CTA 和追踪链接。
核心方法：generatePost(, topic, style) generateTitle(topic, ) generateScript(topic, duration) generateCTA(websiteUrl, utmParams)
依赖：content-intelligence.js traffic-router.js

P2 · website-analytics.js

网站数据
网站 DAU 分析模块。在目标网站部署追踪像素，记录每个访客的来源社媒、来源帖文、来源账号。统计 DAU/MAU/留存率/跳出率。构建转化漏斗：社媒曝光→链接点击→网站访问→注册转化→次日留存。
核心方法：trackVisit(req) getDAU(date) getFunnel(startDate, endDate) attributeSource(visitorId)
依赖：traffic-router.js (UTM解析)

P2 · traffic-router.js

引流路由
引流链接管理系统。为每条帖文/私信/评论生成独立追踪链接，自动拼接 UTM 参数。短链服务将长 URL 转为短链。点击追踪记录每次点击的来源。支持 A/B 测试不同 CTA 文案。
核心方法：createLink(source, medium, campaign, content) shorten(url) trackClick(linkId, metadata) getABVariants(campaignId)
依赖：无（独立模块，被其他模块引用）

⚡ 动态调节示例

场景：下午 3 点，当前 DAU = 4,200，目标 10,000，进度 42%（预期 60%）
自动调节：
• 决策引擎检测到 DAU 缺口 → 触发 adjustStrategy()
• 增加内容产出：从 200帖 → 350帖（调用 AIGC 生成器批量产出）
• 加大主动营销：从 500触达 → 800触达（扩大目标用户搜索范围）
• 启用 S 级紧急发布：SmartPublisher.emergencyPublish() 立即推送高热度内容
• 调整 CTA 策略：AB 测试中表现更好的 CTA 文案自动全量启用
• 降权低效账号：转化率 <0.5% 的账号暂停发布，资源转移给高效账号

全链路的关键路径。没有这一层，云手机无法在社媒上执行任何操作。封装 Playwright 操作为统一接口：发帖、关注、私信、评论、获取 Feed。

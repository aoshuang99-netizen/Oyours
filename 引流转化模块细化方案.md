## 一、现状分析

### 1.1 已有模块概览

| 模块 | 文件 | 行数 | 核心能力 |
|------|------|------|----------|
| **TrafficRouter** | `traffic-router.js` | 429 | 短链生成、UTM、点击追踪、A/B测试路由、转化记录 |
| **WebsiteAnalytics** | `website-analytics.js` | 486 | 访问追踪、会话管理、漏斗分析、实时统计、嵌入式SDK |
| **ProactiveMarketing** | `proactive-marketing.js` | 441 | 营销活动编排、账号协同、话术生成、TrafficRouter联动 |
| **SCRMInterceptEngine** | `scrm-intercept.js` | 539 | 评论截流、关键词评分、回复生成、审核队列 |
| **CloakingGateway** | `server.js` L180-328 | 148 | UA检测、爬虫白页、真人302跳转、DD.txt权重调优 |

### 1.2 已有功能亮点

- **短链系统完整**：base62编码、UTM全参数、多平台来源检测、智能路由规则、A/B测试变体
- **分析体系健全**：访问→会话→访客三级模型、转化漏斗(visited→engaged→signup→paid)、实时在线统计
- **营销自动化**：6种活动类型(关注/私信/话题/KOL截流/竞品截流/矩阵协同)、自动生成追踪链接
- **SCRM截流**：5维加权评分(关键词+时间+互动+情感+用户质量)、S/A/B/C四级决策
- **Cloaking成熟**：11种爬虫检测、合规白页、DD.txt逆向权重调优(转化+30权重、上限500)
- **因果链驱动**：7条EventBus因果链实现"注册→养号→内容→发布→营销→访问→分析→决策"全链路闭环

### 1.3 核心缺口

| 缺口 | 严重度 | 说明 |
|------|--------|------|
| **转化漏斗断裂** | 🔴 高 | TrafficRouter有click→conversion但WebsiteAnalytics有visit→signup→paid，两套漏斗未打通 |
| **无跨渠道归因** | 🔴 高 | 多平台(Reddit/X/Discord/TikTok)各自为战，无法回答"哪个渠道ROI最高" |
| **Cloaking白页单一** | 🟡 中 | 只有一个静态"Horizon Living"模板，不支持多模板/动态内容 |
| **短链无过期/限量** | 🟡 中 | TrafficRouter已设计 expiresAt/clickLimit 字段但未实现自动清理 |
| **A/B测试不成体系** | 🟡 中 | TrafficRouter有abTest配置但无实验管理/统计显著性计算/胜出判定 |
| **无转化价值分层** | 🟡 中 | postback只记录is_converted=1/0，不区分注册/付费/订阅等级 |
| **Landing Page无追踪** | 🟡 中 | 跳转后的用户行为(停留时长、页面深度、表单提交)无回传 |
| **无实时告警** | 🟢 低 | 转化骤降/爬虫检测升级/账号大面积shadowban时无自动通知 |

Lv1    曝光 (Impression)   帖子展示数             平台API/模拟采集

Lv8    复购 (Repeat)       二次购买/续费          Postback回传

## 五、UTM & 归因体系

### 5.1 UTM 参数规范

| 参数 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `utm_source` | ✅ | 渠道来源 | reddit, x, discord, tiktok |
| `utm_medium` | ✅ | 媒介类型 | social, chat, video, dm |
| `utm_campaign` | ✅ | 活动名称 | crypto_launch_2026_q3 |
| `utm_content` | 选填 | 内容变体 | variant_a, image_03 |
| `utm_term` | 选填 | 关键词 | bitcoin, defi, airdrop |
| `utm_device` | 选填 | 设备指纹 | device_12345 |

**短链自动注入规则**：
- 创建短链时，根据 `source` 和 `campaign` 自动拼接 UTM
- 重定向时，保留原始URL中的U+TM参数并追加系统UTM
- 冲突策略：系统UTM优先，原始UTM作为 `utm_original_*`

### 5.2 归因模型

系统支持 4 种归因模型，可在 Landing Page 级别切换：

| 模型 | 逻辑 | 适用场景 |
|------|------|----------|
| **Last Click** (默认) | 转化归功于最后一个触点 | 短周期转化(注册/下载) |
| **Linear** | 所有触点平均分配 | 长决策周期(付费产品) |
| **Time Decay** | 越接近转化的触点权重越高 | 标准电商 |
| **Position Based** | 首次40% + 末次40% + 中间20%均分 | 品牌认知+直接转化并重 |

```javascript
// Landing Page 归因配置
{
  "lp_id": "lp_main",
  "attribution": {
    "model": "position_based",    // 归因模型
    "lookbackDays": 30,           // 回溯窗口
    "creditSplit": {              // Position Based 权重
      "first": 0.40,
      "middle": 0.20,
      "last": 0.40
    }
  }
}
```

```
visitor_id (服务端生成) ──┬── 浏览器 fingerprint (canvas/webgl/audio)
                         ├── localStorage visitor_id

```

L1:  关键词匹配 (已有)

L3: 行为模式检测 (新增: 请求频率/页面深度/JS执行)
L4: TLS指纹检测 (新增: JA3/JA4指纹比对)

响应策略:
L1匹配 → 200白页

// 升级为基于转化质量的动态权重:

 calculateWeightGain(conversion) {
  let base = CONVERSION_TYPES[conversion.type].weight;
  
  // 新账号冷启动加成
  if (account.totalConversions < 10) base *= 1.5;
  
  // 大额转化加成
  if (conversion.value > 100) base *= 1.3;
  
  // 快速转化加成(点击后5分钟内转化)
  let minutesSinceClick = (conversion.time - click.time) / 60000;
  if (minutesSinceClick < 5) base *= 1.2;
  
  // Shadowban 复活加成
  if (account.status === 'shadowbanned') base *= 0.5;  // 降低风险
  
  return Math.round(base * 30);  // 基数30, 范围0-78
}

// 降权机制 (新增)
 calculateWeightLoss(account) {

  // 检测到shadowban → -50

## 附录A: 核心KPI计算公式

```
点击率(CTR)        = 点击数 / 曝光数 × 100%
到达率             = Landing到达数 / 点击数 × 100%
跳出率             = 停留<10s会话 / 总会话 × 100%
注册转化率         = 注册数 / 到达数 × 100%
充值转化率         = 充值数 / 注册数 × 100%
整体转化率(CVR)    = 总转化数 / 总点击数 × 100%
单次转化成本(CPA)  = 总成本(代理+养号) / 转化数
投资回报率(ROI)    = 总佣金 / 总成本
客户终身价值(LTV)  = 平均复购次数 × 平均客单价

渠道效率分         = 转化率 × 0.4 + ROI × 0.3 + 账号存活率 × 0.2 + 增速 × 0.1
```

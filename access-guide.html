🚀 MSCMS v14 访问指南

综合精细化管理系统 — 四种访问方式，按需选择

1. 浏览器直接访问 浏览器 推荐

📡 在线访问

服务器启动后，通过浏览器直接打开控制台。

控制台地址: http://localhost:3002/v14

API 基础路径: http://localhost:3002/api/v14/

启动步骤

1双击 start-mscms.bat 启动服务器
2打开浏览器访问 http://localhost:3002/v14
3开始使用 8 大功能模块

2. Electron 桌面应用 桌面应用

🖥️ 原生桌面体验

独立窗口、系统托盘、无需打开浏览器。关闭窗口后最小化到托盘继续运行。

快速启动

1双击 start-desktop.bat 一键启动
2首次运行自动安装 Electron（约2分钟）
3应用窗口自动打开，服务器随应用启停

手动启动

cd electron

npm install    # 首次需要

npm start

桌面特性

  • 🪟 独立原生窗口 (1400x900, 可调整)
  • 📌 系统托盘常驻 (最小化到托盘, 右键菜单)
  • 🔁 托盘内一键重启服务器
  • 🌐 支持外部浏览器打开
  • 🚫 关闭窗口不退出 (托盘继续运行)

3. 本地安装包 安装器

💿 一键安装到系统

运行安装器，自动配置所有环境，创建快捷方式。

安装步骤

1双击 install.bat 运行安装程序
2自动检查 Node.js、安装依赖
3创建桌面快捷方式和开始菜单
4可选: 添加开机自启动

安装成果

🖥️ 桌面启动 MSCMS v14.lnk / MSCMS v14 控制台.url
📂 开始菜单MSCMS v14 → 启动/控制台/卸载
⚡ 开机自启可选，安装时选择 Y 启用

卸载

运行 uninstall.bat 或从开始菜单选择"卸载 MSCMS v14"

4. 桌面应用打包 安装包

📦 生成独立安装程序

将整个系统打包为 .exe 安装程序或便携版，可分发到其他电脑。

打包步骤

1双击 build-desktop.bat 启动构建工具
2选择打包方式:
  • 选项 2: Windows 安装程序 (.exe 安装包)
  • 选项 3: 便携版 (免安装, 单文件运行)
3构建产物位于 dist-desktop/ 目录

产物说明

MSCMS v14-Setup-3.0.0.exe NSIS 安装程序，带安装向导
MSCMS v14-Portable-3.0.0.exe 便携版，无需安装直接运行

⚡ 快速参考

场景 使用方式 启动命令/文件
快速开发调试 浏览器 node server.js + 浏览器打开 localhost:3002/v14
日常使用 (Web) 浏览器 + 启动脚本 双击 start-mscms.bat
日常使用 (桌面) Electron 桌面应用 双击 start-desktop.bat
新电脑部署 本地安装包 运行 install.bat
分发给他人 打包安装程序 运行 build-desktop.bat → 选2
U盘携带免安装 便携版 运行 build-desktop.bat → 选3

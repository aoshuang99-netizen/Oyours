# Mastodon 发布规则（主力免费通道）

## 准入状态
✅ 已通。2026-09 实测 **4/4 发帖成功**，数据中心 IP 未被封，是 V15 当前最可靠的出口。

## 限流
- 单实例 App 级：建议 ≤ 30 条/分钟；突发超 60/分钟易触发 429。
- 跨实例：每个 Mastodon 服务器独立计限，分散到多实例可线性扩量。
- 退避：遇 429 用指数退避（1s→2s→4s→…→上限 60s），不丢帖。

## 反机器人
- 标准 OAuth 2（App 维度），无设备指纹强校验。
- 风控主要来自**内容重复**与**关注/互动异常**，非 IP。
- 出口：任意可达 IP 即可（无需住宅）。

## 内容格式
- 单条 toot ≤ **500 字符**（超长自动截断或拆串）。
- 敏感/NSFW 内容必须打 **CW（Content Warning）** 折叠（Lok AI 类内容建议默认 CW）。
- 标签 ≤ 5 个，避免 `#spam` 模式。
- 媒体：图片/视频支持，单条 ≤ 4 媒体。

## 算法偏好
- 时间线偏**时间序 + 关注图谱**，无强推荐。
- 冷启动曝光靠：同实例互动、标签可见性、跨实例转发（fediverse）。
- 建议每条带 1–3 个精准标签 + 1 个实例内互动动作（回复/boost 同圈内容）。
